# Josheyer's Historical Modpack

Steam Workshop collection: https://steamcommunity.com/sharedfiles/filedetails/?id=3830508400

95 Crusader Kings III mods, patched together by
[Josheyer Historical Modpack Fixes](https://steamcommunity.com/sharedfiles/filedetails/?id=3797139319).

## Install

1. Subscribe to the collection above.
2. Download [`playset/Josheyer_Historical.json`](playset/Josheyer_Historical.json).
3. Paradox Launcher > Playsets > Import playset > pick the JSON.
4. Start a new game.

`playset/collection_order.txt` is the same load order as plain Workshop IDs.
